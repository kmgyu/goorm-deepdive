기능? 


실시간 장소 혼잡도 API의 경우에 월 10건만 처리가능한 무료 요금제가 있고, 하루 100건 사용 가능한 유료 요금제가 존재해서 요청에 제한이 존재할 듯.
그래서 지역구를 한정한다던가 특정 장소에 대해서만 트래킹을 해야 된다. 그런 것에 대해 논의가 필요할 것 같다.
소상공인 365 API나, 서울시 공공데이터의 랜드마크 실시간 정보 제공 API 등을 대안으로 사용하면 어느정도 보완이 되긴 하겠지만 정확한 정보 주긴 어려울 수 있음.
