질문 뽑아보기

- 혼잡도 회피 시간 추천이라는 기능이 있다. 현재는 모델이라는 패키지 아래에 혼잡도를 예상하는 모델 클래스를 만들어서 그 예측을 기반으로 가장 낮은 혼잡도를 측정하는 방식임.
  여기서 궁금한 부분은 모델 부분. 확장할 때의 계획도 세워야 하는데, 데이터 수집이 부족하므로 AI 모델을 바로 사용할 수는 없다.
  그렇다면 시계열 분석 모형을 사람이 직접 만들어야 할 것이다.
  그런데 시계열 분석 모형도 데이터가 부족해서 못 만든다.
  MVP 완성하고 나서 모델 어떻게 만들어야 할지 고민임.
- static과 component의 차이?
  매퍼랑 유틸 클래스 만들어봤는데 어떤 걸 사용하는 게 좋을 지?
  유지보수 안하는 간단한거면 static 쓰고, spring 프레임워크의 수헤(bean 등록과 그로 인한 로깅이나 aop)를 받을 수 있다. 라고 알고 있음. 예시라던지 부족해서 어떻게 써야할 지 모르겠다.
- CORS 설정 배포에서도 해줘야함?
  같은 도메인에서 CORS 설정해줘야 하는 경우가 있나?
  우리는 nginx로 도메인 설정해주고 리버스 프록시로 백엔드랑 프론트엔드 포트 노출이 안되게 하고 있다.
  원래 백엔드에서 cors 설정해주는데 이거 nginx 있으면 여기서 해주면 됨?
- 리팩토링을 하는 시점은 언제여야 하는지?
  MVP 개발이다보니 개발을 우선적으로 하고 있는데 계속해서 기능 확장을 할 수 있다. 그렇다면 기능 확장을 하다가 리팩토링을 해서 구조를 개선해야 하는 시점은 언제인지 궁금하다.
