추천 기능 - 오늘에 대한 예측, 다른 요일에 대한 예측
오늘이 아니면 predict, 오늘이면 recommend

차이는 그냥 시간대
예측은 09시부터 22시 대상
오늘의 경우 지금 시간(09시 이후)부터 22시 대상
23시부터는 전부 '예측'으로 바뀜.

추가해야 할 가중치 패러미터?
날씨 상황
- 일기 예보 확장 필요
- 그냥 캐싱으로 대체하자 젭라
- 현재 미구현 (데이터는 받아오는데 저장을 안함.)

오늘의 경우 now 시간대도 채워주자. (추천 기능 요구사항 아님)
pred를 통한 예측은 어떻게 해줘야 할까?
