#### 부서 소개

﻿저희 부서는 NAVER Cloud Platform의 API Gateway, Resource Manager, Cloud Log Analytics 서비스를 담당하며, 대량 요청을 안정적으로 처리할 수 있는 고성능·고가용성 서비스 구축을 최우선 목표로 하고 있습니다.  
서비스를 운영하는 과정에서 이벤트 기반 Non-Blocking 처리, 데이터 무결성 유지, 대규모 데이터의 수집·저장·검색 등 핵심 기술 역량을 보유하고 있으며, 각 서비스 간의 기술 교류를 통해 시너지를 창출하고 있습니다.

현재는 글로벌 서비스 강화를 비롯해 소버린 환경에 대응하기 위한 서비스 구조 경량화를 추진하고 있고 지속적으로 증가하는 서비스 사용량에 대응하고 경쟁력을 높이기 위해 기반 기술 역량을 한층 더 강화하고자 합니다.

#### 담당업무

﻿• 서비스 구성 모듈 가상화

﻿• 클라우드 컴퓨팅 자원과의 연계
